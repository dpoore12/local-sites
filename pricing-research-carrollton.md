## Not verified

- The Carrollton fees page does not state an overall effective date, and it names no garage-door
  line item; the anchors are the categories a garage door job actually falls into (residential
  remodel, single-trade electrical for an opener circuit, accessory structure work).
- The city's Contractor Registration page returned a client error when fetched, so no contractor
  registration fee amount is published on the pricing page.
- No BLS metro wage anchor is used for this site: the BLS public data API daily request threshold
  was exhausted before the Dallas-Plano-Irving metro division series (occ 49-9071) could be read,
  and www.bls.gov/oes/current/oes_19124.htm does not render its wage table to a fetcher. The
  figure was therefore left off rather than estimated.

### Carrollton and Denton County operators

**SOS Garage Doors** (Carrollton) - the only fully itemized list found in this market.
- https://www.sosgaragedoors.com/carrollton_overhead_service_springs.html (read 2026-08-23):
  "$39 Service Call + $185 Door Service + Parts"; torsion spring $125 standard or $150 insulated for
  8x7 and 16x7 doors; for 17x7-18x7 doors, door service $215 and springs $165 standard or $185
  insulated.
- https://www.sosgaragedoors.com/carrollton_overhead_repair.html (read 2026-08-23): tune-up special
  $30-$65; full repair $39 service call + $185 door service + parts; cables off in the down position
  $39 + $225; 8x7 stuck open $39 + $285; 16x7 stuck open $39 + $325; add $30 for an 8-ft-tall or
  18-ft-wide door.

**Itemized totals computed from the SOS list**
- Two standard springs, 16x7: $39 + $185 + (2 x $125) = **$474**
- Two insulated-door springs, 16x7: $39 + $185 + (2 x $150) = **$524**  <- sets the high on the spring row
- Two standard springs, 17x7-18x7: $39 + $215 + (2 x $165) = **$584**
- Two insulated springs, 17x7-18x7: $39 + $215 + (2 x $185) = **$624**
- One standard spring, 8x7: $39 + $185 + $125 = **$349**
- Cable off the drum, down position: $39 + $225 = **$264** before parts
- 16x7 door stuck open, cables reset: $39 + $325 = **$364** before parts  <- sets the high on the cable row
