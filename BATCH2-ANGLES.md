# Batch 2 — Angle Assignments

Twenty sites are being written at the same time. Several share a trade, and two
share a city. Find your domain below and build the site on **your assigned
anchor**. This is not a suggestion — it is how the batch avoids twenty writers
independently discovering the same three facts about the same trade.

You still do your own research. The anchor tells you *where to dig*, not what to
conclude. If an anchor turns out to be wrong or unsourceable, say so in your
report and use something else genuinely local.

Read `WRITER-BRIEF.md` first. Everything in it still applies, including the
domain-prefixed temp image filenames.

## Reminders that matter more in a batch this size

- **Legal sites:** no firm name, no attorney name, no case result, no settlement
  figure, no win record, no bar credential, no fee arrangement. Do not write
  "no fee unless we recover" or "free consultation" — the build blocks both.
- **All sites:** the copy sells the work getting done, not a phone conversation.
  Never frame the value as describing your problem out loud.
- **Temp images must be domain-prefixed.** Twenty of you share one workspace.
- Run `python3 template/build.py <yourdomain>` until it passes, then run the full
  `python3 template/build.py` — only the full run cross-checks duplication
  against the other sites.
